About the Project

Project Overview

A comprehensive machine learning project for disease prediction, developed as part of MCA coursework.

🎓 About This Project

The Multiple Disease Prediction System is an academic project that demonstrates the application of machine learning algorithms for healthcare risk assessment. Currently focused on diabetes prediction, the system uses the Pima Indians Diabetes Database and evaluates four different classification algorithms.

This project covers the complete ML pipeline: data loading, preprocessing, exploratory data analysis, model training, evaluation, comparison, and deployment as a web application.

📋 Dataset Information

The Pima Indians Diabetes Database (originally from the National Institute of Diabetes and Digestive and Kidney Diseases) contains diagnostic measurements from 768 female patients of Pima Indian heritage, aged 21 and above.

🔗 Connecting to the Python Backend

This frontend is designed to work with a Flask/FastAPI backend that loads the trained KNN model.

  1. Export your trained model from Colab using joblib.dump()
  2. Set up a Python Flask server with a /predict endpoint
  3. Update BACKEND_URL in js/predict.js to point to your server
  4. Run both the Flask server and open the web app
