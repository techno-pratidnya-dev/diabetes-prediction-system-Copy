ℹ️ About This Tool

This prediction tool uses a K-Nearest Neighbors (KNN) algorithm trained on the Pima Indians Diabetes Database.

How It Works

  1. Enter patient metrics
  2. Data is preprocessed (imputed + scaled)
  3. KNN algorithm compares with training data
  4. Risk assessment is generated
